# 人生模拟器

> 初版写于2026年暑假（大一开学前），2026年9月整理上传至GitHub。

这是我独立完成的第一个Python项目，一个多分支、多结局的交互式文字游戏。

## 功能
- 选择出生季节、抓周，触发不同人生分支
- 包含武术、恋爱、吃货等多条剧情线
- 多种结局

## 我学到了什么
- Python基础语法（if/elif/else、循环、列表、函数）
- 模块调用（os、time）
- 交互式程序设计与剧情分支逻辑
